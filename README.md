# homebrew-tap

Homebrew tap for [Aeris](https://github.com/kashmithnisakya/aeris), your air conditioner in the macOS menu bar.

```bash
brew install --cask kashmithnisakya/tap/aeris
```

Upgrade to the newest release:

```bash
brew upgrade aeris
```

The cask is bumped automatically within about an hour of each Aeris release
(see `.github/workflows/bump-aeris.yml`).
